# Contributing to IntentMandateGuard

Thank you for your interest in contributing to IntentMandateGuard!

## Development Process

1. Fork the repository and create your branch (`git checkout -b feature/enhancement`).
2. Add or update unit tests in `test_mandate_guard.py`.
3. Verify all tests pass locally (`pytest test_mandate_guard.py -v`).
4. Commit your changes and open a Pull Request against `main`.
